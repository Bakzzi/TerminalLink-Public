# 최초 연결

## 같은 네트워크

1. Android 11 이상 휴대폰에 자신이 빌드한 APK를 설치합니다. Android가 요구하는 해당 설치 출처의 설치 허용을 직접 승인합니다.
2. PC 연결 프로그램을 일반 사용자로 실행합니다. Windows Terminal에서 원하는 PowerShell/SSH/Codex 작업을 실행하고, PC 프로그램에서 공유할 창을 선택합니다.
3. 접속 주소에 **휴대폰이 접근할 PC 주소**를 입력합니다. 기본 TCP 포트는 `49443`입니다. `연결 대기 시작`을 누릅니다.
4. Windows 방화벽이 연결을 차단하면 해당 프로그램·포트만 신뢰할 네트워크 범위에서 허용합니다. 방화벽 전체를 끄지 않습니다.
5. PC의 휴대폰 등록 기능으로 QR을 표시하고 Android의 연결 설정에서 스캔합니다. PC에 표시되는 등록 요청을 확인하고 승인합니다. QR은 5분 동안 유효한 비밀값이므로 공유하지 않습니다.
6. 이후에는 등록된 기기의 인증서로 재접속합니다. PC가 계속 켜져 있어야 합니다.

## 다른 네트워크

휴대폰에서 PC 주소에 도달할 경로가 필요합니다. 개인 VPN을 사용하거나 본인이 관리하는 공유기에서 해당 TCP 포트만 PC로 전달할 수 있습니다. 공유기에 따라 외부 IPv4/CGNAT/사내 정책 때문에 포트 전달이 불가능할 수 있습니다. 이 앱은 자동 중계 서버나 공유기 자동 설정을 제공하지 않습니다.

외부 접속을 쓸 경우 앱의 주소를 접근 가능한 VPN 주소 또는 외부 주소로 변경합니다. PC를 관리자 권한으로 실행할 필요는 없습니다. 회사 PC에서는 허용된 범위에서만 사용하세요.

## 알림·첨부·문제 해결

- Android에서 알림 권한을 허용합니다. 저전력 백그라운드 알림은 선택적인 [Firebase](FIREBASE.md) 설정이 필요합니다. 기본 빌드는 연결 유지 서비스와 그 알림을 사용합니다.
- 로컬 Codex 기록은 PC의 실행 사용자 계정에서 읽습니다. 원격 SSH 기록은 [별도 읽기 연결](SSH.md)을 등록해야 합니다.
- 대화를 못 읽거나 입력 대상이 모호하다는 표시는 원본 식별 실패입니다. 터미널에서 정상 실행 중인지와 지원 환경을 확인하세요. 다른 탭의 기록을 임의로 연결하지 않습니다.
- 새 APK가 기존 앱에 설치되지 않으면 서명 키와 versionCode를 확인합니다. 데이터 삭제를 먼저 하지 마세요.
- 배포용 APK를 자신의 PC 프로그램의 업데이트 목록에 넣으려면 `tools/publish-android-update.ps1`을 사용합니다. PC 프로그램 경로를 명시해야 하며 휴대폰 설치는 사용자가 승인합니다.
- 페어링·SSH 비밀번호·푸시 인증정보는 `%LOCALAPPDATA%/TerminalLink`에 보관됩니다. 이 폴더를 타인에게 배포하지 않습니다. 기기 분실 시 PC에서 등록을 해제합니다.

## PC 파일을 임시 파일함에 올리기

사용자가 요청한 파일만 올립니다. 폴더는 먼저 ZIP으로 압축합니다.

```powershell
./tools/share-files.ps1 -Executable './dist/Windows/TerminalLink-PC.exe' -Files 'D:\Exports\report.pdf'
```

모바일의 파일함에서 받습니다. 복사본은 24시간 후 정리 대상이 되며 PC 원본은 유지됩니다. 실제 정리는 프로그램이 실행되며 파일함을 조회/정리할 때 이루어집니다. 파일당 512MB, 최대 32개·총 2GB입니다. 파일 경로 목록과 결과에 개인정보가 포함될 수 있으므로 로그를 공유할 때 확인하세요.

휴대폰에서 올릴 때는 파일함의 **파일 올리기**를 눌러 사진이나 파일을 선택합니다. 인증된 PC에 임시 복사본이 저장되며 같은 파일함을 PC Desktop에서 열어 확인하거나 저장할 수 있습니다. 대화나 터미널에 자동으로 입력하지 않습니다. 업로드한 파일을 Codex에게 보여주려면 파일함의 파일 이름을 말하면 됩니다. 전송 결과를 확인하지 못했을 때는 중복 업로드 전에 파일함 목록을 확인하세요.

Codex의 제한된 작업 폴더 밖에 파일함이 있으면 파일함 스킬이 전용 등록 절차를 사용할 수 있습니다. 전용 실행은 파일함에 지정한 파일을 게시하는 용도이며 임의 PowerShell 명령을 허용하지 않습니다. Codex 명령 예외는 스킬 사용 여부 자체를 구별하지 못하므로 같은 전용 등록 명령을 직접 실행한 경우에도 적용됩니다. 예외 사용은 사용자 설정 및 승인 정책에 따라 달라질 수 있습니다.
