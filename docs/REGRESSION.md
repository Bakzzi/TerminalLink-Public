# 회귀 검증

`tools/test.ps1`은 운영 터미널과 등록 정보를 사용하지 않습니다.

- PC: 표시 변환이 원본을 바꾸지 않음, 복수 질문 답장·잘못된 envelope, citation 코드 예시 보존, 전체/증분 대화 전송, 긴 UTF-8 내용의 청크 복원, 합성 Codex 기록의 추가 읽기.
- 원격 기록: 실제 Python 읽기 코드를 합성 `/proc`·기록 파일로 실행합니다. 답변만 보이는 화면, 다른 SSH 연결·작업 디렉터리·비CLI 원본 거부, 중복 답변의 모호성, 서로 다른 메시지를 합친 증거 거부, 접기 안내 제외, 기존 질문 연결 및 증분·재시작 검증을 포함합니다.
- TLS: 미등록/누락/잘못된 키, 틀린·만료된 등록 토큰, 최초 승인, 재접속, 서버 pin 불일치, 기기 등록 해제, 과대 메시지 거부.
- Android JVM: 실제 요청·알림 코드를 운영체제 대역과 실행. 일시 읽기 실패 시 질문·선택·초안 유지, 재확인, 완료/다른 요청 처리, 연속 알림 답장과 성공·실패 처리.
- 답장 알림 정리: 원본 사용자 답장의 순번, 직접 이벤트·재접속 snapshot·백그라운드 푸시, 다른 탭/PC 및 새 답변 보존, 지연·역순 재전송 방지, 전송 실패와 SystemUI 전송 중 상태, 미응답 요청 보존, 마지막 알림의 요약 제거.
- 빌드: PC self-contained EXE와 서명 APK. 에뮬레이터 없이 수행합니다.

변경하지 않은 범위에 대해 같은 검사를 반복하지 않습니다. 합성 검사 통과를 실제 폰의 설치·UI·OEM 절전 동작이 검증됐다는 의미로 사용하지 않습니다. 실기기 확인에는 새/기존 탭, 읽는 중 네트워크 끊김, 연속 알림 답장, 첨부, 앱 전환을 포함합니다.

개인 대화/캡처는 fixture로 커밋하지 않습니다. 실패를 재현할 때 원인을 보존한 합성 질문·ID·경로로 바꿉니다.

PC self-test의 암호화된 임시 인증서는 `build/tests/pc/test-identity-*` 아래에만 만들어집니다. 배포·Git 대상이 아니며 운영 등록 정보를 재사용하지 않습니다.
