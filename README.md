# TerminalLink

Windows Terminal에서 실행 중인 작업을 Android에서 읽고 입력하는 개인용 원격 터미널입니다. Codex의 원본 기록을 식별할 수 있으면 대화·질문 팝업·답변 알림을 함께 제공합니다.

현재 버전: **0.9.33 · 사전 출시**. Windows PC 연결 프로그램과 Android 앱을 포함합니다. iOS 앱과 독립적인 PC 메신저 UI는 포함하지 않습니다. 이 프로젝트는 OpenAI의 공식 제품이 아닙니다.

## 처음 사용하기

1. [빌드 안내](docs/BUILD.md)에 따라 PC 프로그램과 APK를 만듭니다. 기본 빌드는 Firebase 계정 없이 가능합니다.
2. PC에서 `dist/Windows/TerminalLink-PC.exe`를 실행하고 공유할 **Windows Terminal** 창을 선택합니다. Windows Terminal 안에서 PowerShell이나 SSH를 사용합니다.
3. [연결 안내](docs/SETUP.md)에 따라 휴대폰에 APK를 설치하고 QR로 최초 등록합니다. QR 등록은 PC의 승인까지 필요합니다.
4. Android에서 탭을 선택해 터미널·대화·요청을 사용합니다. 원격 SSH 대화 기록은 별도의 [읽기 연결 등록](docs/SSH.md)이 필요합니다.

첫 등록 후에는 두 기기에 생성된 인증서로 서로 확인합니다. 저장소에 공용 비밀번호, 개발자 기기 키, Firebase 프로젝트 설정은 없습니다. 각 사용자가 자신의 PC·휴대폰에서 등록합니다.

## 기능과 현재 한계

- 기존 Windows Terminal 작업을 유지하며 텍스트와 입력을 공유합니다. 터미널 UI와 Codex 원본 기록은 서로 다른 데이터입니다.
- 원본 기록의 소유권과 대화 일치를 확인한 경우 대화와 요청을 제공합니다. 모호하거나 읽지 못하면 오류로 표시하며, 화면 일부를 전체 대화로 대체하지 않습니다.
- 답변·요청 알림과 알림 답장, 이미지·파일 첨부, 사용자가 지정한 임시 파일함을 지원합니다. 일부 기능은 해당 대화의 안전한 입력 대상 확인이 필요합니다.
- 기본 빌드는 백그라운드 연결을 유지하므로 Android의 연결 알림과 배터리 제한이 적용됩니다. 저전력 푸시를 사용하려면 [자신의 Firebase 설정](docs/FIREBASE.md)을 추가해야 합니다.
- Codex 버전, 터미널 상태, 중복된 질문, SSH 서버 환경에 따라 원본 연결이나 입력을 확인하지 못할 수 있습니다. 모든 환경의 정상 동작을 보장하는 안정판은 아닙니다.
- PC가 꺼지거나 네트워크 연결이 끊어지면 사용할 수 없습니다. 이 프로그램은 작업 세션을 재부팅 후 자동 복원하지 않습니다.
